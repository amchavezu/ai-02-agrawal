# Course context - UP 2026-II

Source: `course/materials/syllabus-2026-II.pdf`. This is a concise project map, not a
replacement for the official syllabus.

## Course

- **Name:** Artificial Intelligence and Economic Modeling.
- **Term:** 10 August to 21 November 2026.
- **Format:** virtual, Wednesday and Friday, two hours per session.
- **Method:** read, reproduce, and extend recent formal economic models; use LLMs as
  audited proof assistants rather than substitutes for judgment.
- **Prerequisites:** microeconomics, calculus and optimisation, probability and statistics,
  and econometrics.

## Evaluation

| Component | Weight |
|---|---:|
| Final paper (6-8 pages plus handwritten appendix) | 30% |
| Final presentation | 30% |
| Six weekly repositories (20%) plus topic presentation (10%) | 30% |
| Five-minute oral reading check | 10% |

There are no written midterm or final exams.

## Weekly repository rule

- New GitHub repository for each designated paper.
- Deadline: Tuesday at 22:00.
- Work through branch -> pull request -> merge; nothing written directly to `main`.
- Minimum contents: one-page `README.md`, raw `prompts.md`, a real photo in `hand/`,
  and a compiled five-minute Beamer deck.
- The repository link must be registered even if the student is not drawn for the oral exam.

## Five-minute deck

The title slide contains the repository URL, followed by exactly four slides:

1. Paper, single mechanism, and explicit agent problem.
2. Exact main proposition, all conditions, and one-sentence intuition.
3. What the student explored, including failed paths when explained.
4. Where the student did not believe the AI, the hand check, and a justified verdict.

No animations and no screenshots of the paper; equations must be written in LaTeX.
