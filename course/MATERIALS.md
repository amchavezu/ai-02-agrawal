# Course materials in this repository

The original PDFs are stored locally in `course/materials/` for consultation. Git ignores
those files so that course documents are not republished accidentally in the public
assignment repository. This file records the durable material map instead.

## `materials/syllabus-2026-II.pdf`

Official course structure, learning outcomes, grading, weekly-repository rules, academic
integrity policy, bibliography, and semester calendar.

## `materials/part2-intuition-beamer.pdf`

Fifty-two intuition-first slides for Aouad, Lykouris, and Zhong (2026), Part II. The key
economic chain is AI assistance -> lower effort -> slower skill accumulation -> a downward
shift in stationary skill -> a potentially negative composition effect. This is background
from Week 1 and is not evidence for the Agrawal paper.

## `materials/applied-codex-cli-tutorial.pdf`

Thirty-three slides on repository-oriented Codex work: start in the correct directory,
inspect before editing, state outcome/scope/constraints/evidence, use `AGENTS.md` for durable
rules, verify generated artifacts visually, and use Git as the control surface.
